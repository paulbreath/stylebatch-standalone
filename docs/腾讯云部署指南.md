# StyleBatch 腾讯云部署指南

**方案B：稳定可靠版**

---

## 📋 部署概览

本指南将帮助您将 StyleBatch 应用部署到腾讯云，采用稳定可靠的云数据库方案，确保应用的高可用性和可扩展性。

### 架构组成

- **腾讯云轻量应用服务器**：托管 Node.js 应用（前端 + 后端 API）
- **腾讯云数据库 MySQL**：存储用户数据和转换记录
- **腾讯云对象存储 COS**：存储上传的图片和转换结果
- **腾讯云 CDN**：加速静态资源和图片访问

## 🚀 部署步骤

### 第一步：购买腾讯云轻量应用服务器

#### 1.1 登录腾讯云控制台

访问 [腾讯云轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse/instance/index)，登录您的腾讯云账号。

#### 1.2 创建实例

点击"新建"按钮，选择以下配置：

- **地域**：选择离您目标用户最近的地域（如广州、上海、北京）
- **镜像**：选择"应用镜像" → "Node.js"（推荐 Node.js 22.x）
- **套餐**：选择"2核4GB 80GB SSD 6Mbps"
- **时长**：建议先选择 1 个月测试，后续可续费

#### 1.3 配置实例

- **实例名称**：`stylebatch-server`
- **密码**：设置一个强密码（用于 SSH 登录）
- **防火墙**：开放以下端口
  - `22`（SSH）
  - `80`（HTTP）
  - `443`（HTTPS）
  - `3000`（应用端口，可选）

点击"立即购买"，等待实例创建完成（约 1-2 分钟）。

#### 1.4 连接到服务器

实例创建完成后，点击"登录"按钮，或使用 SSH 客户端连接：

```bash
ssh ubuntu@<服务器公网IP>
```

---

### 第二步：配置服务器环境

#### 2.1 更新系统

```bash
sudo apt update && sudo apt upgrade -y
```

#### 2.2 安装 Node.js 和 pnpm

如果镜像已包含 Node.js，跳过此步骤。否则执行：

```bash
# 安装 Node.js 22.x
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 pnpm
sudo npm install -g pnpm

# 验证安装
node --version  # 应显示 v22.x.x
pnpm --version
```

#### 2.3 安装 PM2（进程管理器）

```bash
sudo npm install -g pm2

# 设置 PM2 开机自启
pm2 startup
sudo env PATH=$PATH:/usr/bin pm2 startup systemd -u ubuntu --hp /home/ubuntu
```

#### 2.4 安装 Nginx（反向代理）

```bash
sudo apt install -y nginx

# 启动 Nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 第三步：创建腾讯云数据库 MySQL

#### 3.1 进入云数据库控制台

访问 [腾讯云数据库 MySQL 控制台](https://console.cloud.tencent.com/cdb)。

#### 3.2 创建实例

点击"新建"，选择以下配置：

- **计费模式**：按量计费（灵活，可随时销毁）
- **地域**：与轻量服务器相同地域
- **数据库版本**：MySQL 8.0
- **架构**：基础版
- **规格**：1核1GB
- **硬盘**：20GB
- **网络**：默认 VPC
- **安全组**：允许轻量服务器访问（添加服务器 IP 到白名单）

#### 3.3 初始化数据库

实例创建完成后：

1. 点击实例 ID 进入详情页
2. 记录**内网地址**（如 `10.x.x.x:3306`）
3. 点击"账号管理" → "创建账号"
   - 账号名：`stylebatch`
   - 密码：设置强密码
   - 主机：`%`（允许所有 IP）
   - 权限：读写权限
4. 点击"数据库管理" → "创建数据库"
   - 数据库名：`stylebatch`
   - 字符集：`utf8mb4`
   - 排序规则：`utf8mb4_unicode_ci`

#### 3.4 测试连接

在服务器上安装 MySQL 客户端并测试连接：

```bash
sudo apt install -y mysql-client

mysql -h <内网地址> -P 3306 -u stylebatch -p
# 输入密码后，如果成功连接，输入 exit 退出
```

### 第四步：配置腾讯云对象存储 COS

#### 4.1 创建存储桶

访问 [腾讯云对象存储控制台](https://console.cloud.tencent.com/cos)。

1. 点击"存储桶列表" → "创建存储桶"
2. 配置：
   - **名称**：`stylebatch-images-<随机数>`（全局唯一）
   - **所属地域**：与服务器相同地域
   - **访问权限**：公有读私有写
   - **其他**：保持默认

#### 4.2 配置 CORS

点击存储桶名称进入详情页，选择"安全管理" → "跨域访问 CORS 设置" → "添加规则"：

```json
{
  "AllowedOrigins": ["*"],
  "AllowedMethods": ["GET", "PUT", "POST", "DELETE", "HEAD"],
  "AllowedHeaders": ["*"],
  "ExposeHeaders": [],
  "MaxAgeSeconds": 3600
}
```

#### 4.3 获取访问密钥

访问 [API 密钥管理](https://console.cloud.tencent.com/cam/capi)：

1. 点击"新建密钥"
2. 记录 **SecretId** 和 **SecretKey**（用于代码中访问 COS）

### 第五步：部署应用代码

#### 5.1 导出代码到 GitHub

在 Manus 管理界面：

1. 点击"设置" → "GitHub"
2. 选择 GitHub 账号和仓库名称
3. 点击"导出代码"

#### 5.2 克隆代码到服务器

```bash
cd /home/ubuntu
git clone https://github.com/<your-username>/<repo-name>.git stylebatch
cd stylebatch
```

#### 5.3 安装依赖

```bash
pnpm install
```

#### 5.4 配置环境变量

创建 `.env` 文件：

```bash
nano .env
```

填入以下内容（替换为您的实际值）：

```env
# 数据库配置
DATABASE_URL=mysql://stylebatch:<密码>@<内网地址>:3306/stylebatch

# JWT 密钥（生成随机字符串）
JWT_SECRET=<生成一个64位随机字符串>

# 腾讯云 COS 配置
COS_SECRET_ID=<您的SecretId>
COS_SECRET_KEY=<您的SecretKey>
COS_BUCKET=stylebatch-images-<随机数>
COS_REGION=<地域，如ap-guangzhou>

# 火山引擎 API（如果使用）
VOLCENGINE_ACCESS_KEY=<您的AccessKey>
VOLCENGINE_SECRET_KEY=<您的SecretKey>
VOLCENGINE_ARK_API_KEY=<您的ARK API Key>

# Replicate API（如果使用）
REPLICATE_API_TOKEN=<您的Replicate Token>

# Gemini API（如果使用）
GEMINI_API_KEY=<您的Gemini API Key>

# 应用配置
NODE_ENV=production
PORT=3000
VITE_APP_TITLE=StyleBatch
VITE_APP_LOGO=/logo.svg
```

保存并退出（Ctrl+X，然后 Y，然后 Enter）。

**生成 JWT_SECRET：**

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

#### 5.5 初始化数据库

```bash
pnpm db:push
```

#### 5.6 构建应用

```bash
pnpm build
```

#### 5.7 启动应用

```bash
pm2 start npm --name "stylebatch" -- start
pm2 save
```

验证应用运行：

```bash
pm2 status
curl http://localhost:3000
```

### 第六步：配置 Nginx 反向代理

#### 6.1 创建 Nginx 配置文件

```bash
sudo nano /etc/nginx/sites-available/stylebatch
```

填入以下内容：

```nginx
server {
    listen 80;
    server_name <您的域名或服务器IP>;

    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 300s;
        proxy_connect_timeout 75s;
    }
}
```

#### 6.2 启用配置

```bash
sudo ln -s /etc/nginx/sites-available/stylebatch /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置
sudo systemctl reload nginx
```

### 第七步：配置域名和 SSL 证书

#### 7.1 绑定域名

在您的域名注册商处，添加 A 记录：

- **主机记录**：`@` 或 `www`
- **记录类型**：A
- **记录值**：服务器公网 IP
- **TTL**：600

#### 7.2 安装 SSL 证书（Let's Encrypt 免费证书）

```bash
sudo apt install -y certbot python3-certbot-nginx

# 自动配置 SSL
sudo certbot --nginx -d <您的域名>

# 设置自动续期
sudo certbot renew --dry-run
```

按照提示完成配置，Certbot 会自动修改 Nginx 配置并重启服务。

## 🛠️ 常见问题

### 1. 应用无法启动

**检查日志：**

```bash
pm2 logs stylebatch
```

**常见原因：**
- 环境变量配置错误
- 数据库连接失败
- 端口被占用

### 2. 数据库连接失败

**检查安全组：**
- 确保轻量服务器 IP 在数据库白名单中
- 确保数据库实例状态为"运行中"

**测试连接：**

```bash
mysql -h <内网地址> -P 3306 -u stylebatch -p
```

### 3. 图片上传失败

**检查 COS 配置：**
- 确保 SecretId 和 SecretKey 正确
- 确保存储桶权限为"公有读私有写"
- 确保 CORS 配置正确

### 4. Nginx 502 错误

**检查应用状态：**

```bash
pm2 status
curl http://localhost:3000
```

**检查 Nginx 配置：**

```bash
sudo nginx -t
```

## 📊 性能优化建议

### 1. 启用 Gzip 压缩

编辑 Nginx 配置：

```nginx
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss application/rss+xml font/truetype font/opentype application/vnd.ms-fontobject image/svg+xml;
```

### 2. 配置 CDN 加速

在腾讯云 CDN 控制台：

1. 创建 CDN 加速域名
2. 源站类型选择"对象存储 COS"
3. 选择您的 COS 存储桶
4. 配置 CNAME 解析

### 3. 数据库优化

- 定期备份数据库
- 监控慢查询日志
- 根据访问量调整实例规格

### 4. 应用优化

- 使用 Redis 缓存热点数据（可选）
- 配置图片 CDN 加速
- 优化数据库查询索引

## 🔐 安全建议

### 1. 服务器安全

```bash
# 禁用 root 登录
sudo nano /etc/ssh/sshd_config
# 设置 PermitRootLogin no

# 配置防火墙
sudo ufw allow 22
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable

# 定期更新系统
sudo apt update && sudo apt upgrade -y
```

### 2. 数据库安全

- 使用强密码
- 定期备份数据库
- 限制访问 IP（仅允许服务器 IP）

### 3. API 密钥安全

- 不要将密钥提交到 Git 仓库
- 定期轮换 API 密钥
- 使用腾讯云 CAM 权限管理
